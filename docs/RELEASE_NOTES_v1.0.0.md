# CampusNotes v1.0.0

## Highlights

- Added a Python command-line interface to add, list, search and display campus notes.
- Added validation to reject empty note titles and bodies.
- Persisted notes in a per-user JSON store with atomic file replacement.
- Added standard-library unit tests for persistence, validation and search.
- Added shared Git hooks for staged unfinished-work markers and Conventional Commit messages.

## Compatibility

- Python 3.10 or newer
- No third-party runtime dependencies
